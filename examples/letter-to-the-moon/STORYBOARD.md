# 《我爱你》MG 动画 MV · 分镜与视觉规格

> 视觉命题：**墨潮月信 / A LETTER TO THE MOON**
> 一封没有寄出的信，穿过墨海、红线、镜面、逆雨和字城，最终抵达月亮，化成海面上的一层光。
> 音乐：王菲《我爱你》（张亚东《潜流》版本，5:10.16，72 BPM，Dream-pop / Downtempo）

## 一、全局美术体系

### 1. 色彩
| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 玄墨 | `#060A16` | 天幕、深水、黑场 |
| 夜蓝 | `#0A1328` | 海面、雾、阴影 |
| 月银 | `#E7EDF5` | 月光、纸边、字幕主体 |
| 宣纸 | `#E8E0CF` | 信纸、纸鹤、纸阶、伞面 |
| 朱砂 | `#C94535` | 火漆印、红线、情绪重音 |
| 鎏金 | `#C8A96B` | 极小面积暖光、火漆高光 |
| 雾青 | `#5C7C9E` | 中景空气、反射、冷光 |

**比例约束**：玄墨/夜蓝 ≥ 70%，月银/宣纸 20%，朱砂 ≤ 7%，鎏金 ≤ 3%。红色只出现在“信物/情绪”上，不做大面积背景。

### 2. 质感
- 宣纸纤维、墨的扩散、银盐颗粒、薄雾、玻璃与水面反射。
- 所有纸制品保留轻微卷边/纤维；信纸正面有极淡的手写笔画与「见字如面」。
- 不用照片素材、不用写实人物；人物只以纸剪影/远景出现。

### 3. 字体
- 中文：思源宋体 Noto Serif SC（300 / 400 / 600），宽字距。
- 英文：Cormorant Garamond（Roman / Italic），全大写小字距或斜体。
- 字幕：中文 30–34px，英文 12–14px，位于画面下方 8–12% 安全区。
- 片名：巨大、极细、逐字显影；英文副题用字距拉开的斜体。

### 4. 运镜语法
- 主镜头：35–85mm 等效焦段；舒缓推拉、摇臂、半环绕、穿越。
- 每个主镜头至少 1 次“空间揭示”（升起/推进/穿镜）。
- 大能量点才允许快速甩镜/闪白；其余保持克制。
- 手持呼吸幅度 < 0.06 单位，卷帘 < 0.15°。
- 画面比例 2.39:1；24fps 成片。

### 5. 动画层级（每个镜头都要有）
1. 相机运动（位置/目标/焦距/滚转）
2. 主体表演（信、纸鹤、红线、伞、剪影）
3. 环境循环（海浪、雾、雨、粒子、光柱）
4. 音乐响应（低频呼吸、中频微光、高频闪烁、重音脉冲）
5. 细节层（前景散景、尘埃、纸纤维、光晕）
6. 转场层（墨渗/朱砂闪/月环/黑场）

### 6. 转场体系
- **墨渗**：程序化 fBm 墨迹从边缘吞没画面，切镜点在全黑帧。
- **朱砂闪**：强拍上的 6–10 帧暖红闪，切镜。
- **月环**：圆形光孔收缩/扩张，用于月相关键节点。
- **黑场呼吸**：极短的纯黑停顿，只用于 1:44 的“屏息”。
- **硬切**：只用于同场景内的机位切换。

## 三、分镜逻辑链（为什么这样排）

1. **起**：墨滴 = 一个念头；片名出现即“信件写下”。
2. **承**：海、鱼、纸阶 = 信离开书写者，进入记忆的通道。
3. **转**：红线 = 思念最浓；屏息 = 不敢说出口；镜面 = 自我怀疑；镜碎/逆雨 = 情绪崩塌。
4. **再转**：字城 = 语言本身成为阻碍；坠落 = 放弃抵达。
5. **合**：水下月渡 = 在无法抵达时仍然上升；穿月 = 越过执念；星海/成字 = 爱不再是抵达，而是一封信走了很远。
6. **余**：空海、月落、最终「我爱你」 = 说出口，但不再要求回应。

## 四、验收清单

- [ ] 每个镜头的相机运动不是匀速直线，有起势/落势。
- [ ] 同一镜头内至少 5 个独立动画层（相机、主体、环境、音乐响应、细节）。
- [ ] 信纸/火漆/红绳/纸鹤的几何接缝对齐，无穿插与错位。
- [ ] 月亮在跨镜头时方位与光向连续。
- [ ] 字幕在安全区内，淡入淡出；不遮挡主体面部/信纸核心。
- [ ] 段落切换对齐音乐强拍或结构点；1:44 屏息有真正的静止感。
- [ ] 色彩比例符合 70/20/7/3 约束。
- [ ] 成片 1920×804、24fps、H.264，音轨与画面同步。
