# 10 · 踩坑清单：43 条，按工序排

> 每条格式：**现象 → 原因 → 修法**。带「事故」标记的是本项目真实踩过的。

## 0. 立项与流程

**1. 风格每 20 秒漂移一次**
现象：每个场景单看都好，连起来像合集。
原因：没有冻结 `art-direction.json`，每个场景各自调色。
修法：Gate A 后锁死色板/材质/字体/后处理；改动必须写 changelog。

**2. 在错误的结构上打磨材质**
现象：材质很精致，但片子不好看。
原因：分镜没定就进搭建。
修法：先做 animatic；结构通过后再 look-dev。

**3. 一次改三个变量**
现象：改了机位+灯光+颜色，结果变好了/变坏了都不知道为什么。
原因：没有控制变量。
修法：一次只改一个；截图对比；记录在案。

**4. 30 秒能验证的事拖到 5 分钟**
现象：全片做完才发现风格不对。
原因：没有先做预告版。
修法：任何长片先做 30 秒版，过 Gate A/B/C。

**5. 用户说「再高级一点」就乱改**
现象：越改越花。
原因：把模糊反馈当指令。
修法：追问「更暗/更慢/更空/更精细」；转成一个具体字段。

## 1. 音乐与时间

**6. 只用 RMS 驱动一切**
现象：画面在动，但和歌没关系；副歌和主歌一样。
原因：只看能量，没有段落/人声/频谱。
修法：三层时间尺度（段落/乐句/事件）；不同特征映射不同参数。

**7. 切点正好落在峰值上**
现象：高潮「迟到」，感觉不爆。
原因：人眼需要 100–200ms 识别新画面。
修法：峰值前 1–2 拍切；峰值镜头本身要最强。

**8. 自动分段错半句**
现象：段落切换在歌词中间。
原因：渐变编曲/弱拍起。
修法：人工听 + 波形校正；段落边界吸附到 onset。

**9. 全片镜头一样长**
现象：像幻灯片。
原因：按 BPM 机械切。
修法：镜长跟随能量；至少一个长镜和一个短镜。

**10. 转场没有居中在切点【事故】**
现象：节奏「拖半拍」/「抢半拍」。
原因：转场从切点开始或结束。
修法：`start = cut - dur/2`；QA 排除转场窗口。

**11. 音频比视频长 0.1 秒**
现象：最后一帧黑/声音被截。
原因：没加 `-shortest` 或时长没对齐。
修法：视频按音频时长渲染；`-shortest`；校验末帧。

**12. 用墙钟做动画**
现象：每次渲染结果不同；暂停后画面跳。
原因：`Date.now()`/rAF 累积。
修法：纯 `render(t)`；固定 seed；导出不依赖实时。

## 2. 分镜与叙事

**13. 连续三个镜头同景别/同机位**
现象：观众疲劳，像重复。
原因：没有景别节奏。
修法：每次切镜至少改变两项（景别/角度/运动/色温）。

**14. 一个镜头讲两件事**
现象：观众不知道看哪。
原因：贪心。
修法：一镜一事件；拆成两镜。

**15. 镜头删掉也不影响理解**
现象：片子拖。
原因：没有功能。
修法：每镜标注功能；删掉冗余镜。

**16. 结尾停在随便一个空镜**
现象：没有落点。
原因：没设计最后画面。
修法：结尾回到母题的最终形态；片尾卡留 4–6 秒。

**17. 转场种类太多**
现象：花哨、廉价。
原因：每个切点都想炫技。
修法：全片 ≤5 种，每段 ≤2 种；默认 cut。

**18. 字幕是歌词的复读机**
现象：像 KTV；版权风险。
原因：直接贴歌词。
修法：原创诗行；歌词需用户提供并确认授权。

## 3. 运镜与构图

**19. 镜头穿过几何体**
现象：画面闪一下/出现内部。
原因：路径没检查；near 太小。
修法：near 0.01–0.05；路径采样 + Raycaster；留 0.3 余量。

**20. 主体被前景完全挡住【事故】**
现象：关键镜头「看不见信」。
原因：只看了一帧/没测可见性。
修法：5×5 射线采样 + 隐藏差分；QA 门禁。

**21. 探针选错对象【事故】**
现象：探针报告 dot=0.78（可见），实际画面没有主体。
原因：按位置/类型选到了同位置的灯。
修法：断言对象身份/世界坐标；用 `subjectMeshes` 白名单。

**22. 环绕超过 180°**
现象：晕、方向混乱。
原因：想「炫」。
修法：90–120°；半径 ≥ 主体 2 倍。

**23. look 目标穿过 up 轴**
现象：画面突然翻转。
原因：lookAt 奇异点。
修法：限制俯仰 <85°；用 quaternion；look 目标不穿过主体。

**24. 抖动太大/太快**
现象：像地震/故障。
原因：幅度 0.1+、频率 3Hz+。
修法：0.02–0.05；0.5–2Hz；固定镜头不加。

**25. 推轨像变焦**
现象：透视不对，观众不适。
原因：fov 变化太大。
修法：fov 变化 ≤8°；用位置推。

**26. 切镜后运动方向反了**
现象：观众「撞墙」。
原因：没做屏幕方向连续性。
修法：分镜加 `direction`；反向时加缓冲镜。

**27. 2.39:1 构图照搬 16:9**
现象：左右空/主体太小。
原因：没重新构图。
修法：宽画幅用三分法/前景；竖版单独渲染。

## 4. 场景与渲染

**28. 主体像贴上去的**
现象：没有立体感/落地感。
原因：先做主体后做光；没有接触阴影。
修法：先背景+光；加接触阴影/AO；前景遮挡。

**29. 透明排序闪烁**
现象：墨/水/纸边缘闪。
原因：透明物体深度写入/排序。
修法：`depthWrite:false`；固定 renderOrder；`alphaTest`。

**30. Bloom 全屏发光**
现象：灰、糊、廉价。
原因：threshold 太低/strength 太高。
修法：threshold 0.8+；strength 0.2–0.4；只给高光。

**31. 纯黑/纯白**
现象：死黑、刺眼。
原因：黑位 0、白位 1。
修法：黑位 0.01–0.02（带色）；白位 0.95。

**32. 颜色空间错误**
现象：贴图发灰/过饱和。
原因：albedo 没设 sRGB；数据贴图设了 sRGB。
修法：颜色贴图 sRGB；normal/roughness 线性。

**33. 字体没加载就测量**
现象：排版错位/回退字体。
原因：`document.fonts.ready` 没等。
修法：等字体；加载后 `requestAnimationFrame` 重测。

**34. 中文子集缺字【事故】**
现象：某个字幕出现豆腐块。
原因：子集化时漏了字/改文案没重新子集。
修法：从所有文案收集字符；交付前逐条渲染检查。

**35. 字幕挡主体**
现象：关键画面被字盖住。
原因：没测碰撞。
修法：重叠 <15%；移字幕/移机位/拆句。

**36. 字幕底板太黑/太大**
现象：画面脏。
原因：固定黑底。
修法：按局部亮度自适应；柔边；透明度 ≤0.6。

**37. 3D 文字糊/锯齿**
现象：片名廉价。
原因：SDF 分辨率不够/字号太小。
修法：小字用 Canvas 纹理；SDF 图集加大；MSAA。

**38. 粒子太多/太亮**
现象：噪点、卡顿。
原因：没有预算。
修法：<2 万（加色 <5 万）；大小衰减；半分辨率。

**39. shader 首次编译卡顿**
现象：第一帧黑/长等待。
原因：没预热。
修法：每个场景先渲染中段一帧；再开始导出。

**40. 渲染上下文丢失/TDR**
现象：跑一半崩溃/白屏。
原因：GPU 超时/显存。
修法：分块渲染 + `--resume`；降分辨率/关阴影；监控显存。

## 5. 导出与 QA

**41. 录屏/截图拼视频【事故】**
现象：有浏览器 UI、掉帧、颜色不对。
原因：用系统截图/录屏。
修法：纯 `render(t)` + `toDataURL` 同任务读回。

**42. 导出全范围 yuvj420p【事故】**
现象：成片发灰/死黑，和预览不一致。
原因：JPEG 输入默认 full range。
修法：`scale=in_range=full:out_range=limited:in_color_matrix=bt709:out_color_matrix=bt709,format=yuv420p` + BT.709 标签。

**43. 截图工具跑到一半永久挂起【事故】**
现象：`qa-cdp` / `export` 在第 N 帧后不再输出，进程不退出也不报错；浏览器还在，页面 `__MV.ready` 为 true。
原因：4MB 以上的 PNG data URL 通过 CDP 返回。开了 `Network.enable` 后，`img.src = dataURL` 会被当成一次请求事件，几十 MB 的 `Network.dataReceived` 直接把 WebSocket 撑断（close 1006）。旧客户端没有 `close`/`error` 处理，未决的 Promise 永远不 resolve。
修法：三件事一起做——① 客户端监听 `close`/`error`，把所有 pending 全部 reject，并给每次调用加超时；② 大字符串分块读（`slice(off, off+1MB)` 多次 `Runtime.evaluate`），不要一次 `returnByValue`；③ 页面内解码用 `atob → Uint8Array → Blob → createImageBitmap`，**不要** `img.src = dataURL`。参考实现 `tools/lib/cdp.mjs`。

## 附：QA 误报清单（都发生过）

| 误报 | 原因 | 正确处理 |
|---|---|---|
| 27 个黑帧 | 转场居中在切点，边界帧本来就暗 | 排除转场窗口，不要改画面 |
| 静止镜头被判冻结 | 刻意的呼吸镜头 | 分镜标记 `still:true`，白名单 |
| VMAF 没分数 | `-loglevel error` 吞了输出 | 用 info 级别；检查 log 文件 |
| 音频 0.0dB 被判削波 | 源本身就这样 | 保持忠实；让用户换源，不要硬压 |
| VMAF 只有 1.07 | 参考只传了第一张 `000001.jpg`，每帧都在和同一张比 | 参考必须是 `%06d` 帧序列 |
| VMAF 分数倒挂/极低 | `libvmaf` 的两个输入顺序写反（它要 distorted 在前、reference 在后） | 先 `-i film.mp4`，再 `-i frames/%06d.jpg` |
| SSIM 0.75 但肉眼看一样 | 参考与成片分辨率/帧率/像素格式没对齐 | 两边都 `scale` 到同尺寸 + `format=yuv420p` + `setpts=PTS-STARTPTS` |
| 全片报闪烁 | `photosensitivity` 把已登记的 `flash` 也算进去 | 用分镜的 flash 时间窗做白名单 |
| 黑帧都落在转场附近 | 黑段与转场窗口重叠 >60% 就是转场本身 | 传 `--storyboard`，只看剩下的黑段 |

## 附：三条元规则

1. **先测再改。** 没有测量数据的「修复」都是猜。
2. **一次一个原因。** 同时改三处，好了也不知道为什么好。
3. **记录结论。** 每次 Gate 的结论写进文件；上下文会丢，文件不会。
