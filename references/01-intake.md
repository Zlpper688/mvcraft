# 01 · 问询、母题与 treatment

> 用户只给「一首歌 + 我想做个 MV」。这一章把它变成一句话母题、一份 treatment、一套锁定的美术方向。

## 1.1 为什么必须问，但只问 5 分钟

不问的代价：用户拿到一部「技术上正确、气质完全不对」的片子，返工等于重做。
问太多的代价：用户失去耐心，Agent 变成问卷调查。

原则：**只问那些改变结构的题**。

- 「喜欢什么风格」→ 结构（材质、光、镜头、字体全部不同）
- 「要不要叙事」→ 结构（分镜方式完全不同）
- 「有没有歌词」→ 合规 + 排版（字幕系统不同）
- 「横版还是竖版」→ 构图（同一镜头要重新设计）
- 「你要什么颜色」→ **不该问**，应该给色板选
- 「Bloom 多少」→ **不该问**，这是你的工作

## 1.2 问询脚本（可直接用）

第 1 题（气质，单选，带 3 张参考图）：

| 选项 | 关键词 | 代表的片子 |
|---|---|---|
| 墨 / 纸 / 水 | 留白、慢、物象、东方 | 《卧虎藏龙》片头、山水动画 |
| 胶片城市 | 颗粒、雨、霓虹、怀旧 | Wong Kar-wai、王家卫夜戏 |
| 星海史诗 | 大尺度、冷光、缓慢升起 | 《星际穿越》对接、Terrence Malick |
| 极简排版 | 网格、黑白、精确 | 瑞士国际主义、Kinetic type |
| 故障 / 赛博 | 扫描线、锐利、过曝 | Blade Runner、Akira 片头 |

第 2 题（叙事）：
- 物象旅程（一封信/一颗种子/一束光，从 A 到 B）
- 第一人称记忆（碎片、闪回、同一场景反复变形）
- 纯视觉（只有节奏与形态，无角色无故事）
- 我自己的故事（让用户写 2–3 句）

第 3 题（尺度）：微距 / 人尺度 / 史诗 / 混合
第 4 题（文字）：无字 / 原创诗性字幕 / 用户提供歌词 / 只要片名卡
第 5 题（画幅 + 时长）：2.39:1 / 16:9 / 9:16；30 秒 / 全曲
第 6 题（交付）：网页 / MP4 / 两者

**选项要说人话，不要术语。** 不说「高对比低饱和补色」，说「黑、银、一点红」。

## 1.3 从一句话到母题

一句话通常是「概念」，不是「画面」。母题必须是**可被看见、可被重复、可被变形**的东西。

| 用户的一句话 | 概念 | 可拍的母题 | 变形的三个阶段 |
|---|---|---|---|
| 「我想表现思念」 | 缺席 | 一封没有收件人的信 | 写完 → 寄不出 → 成为海面上的光 |
| 「城市让我窒息」 | 压迫 | 不断收窄的窗/巷 | 街道 → 电梯井 → 只剩一条缝 |
| 「重新开始」 | 更新 | 一颗倒放的种子 | 埋下 → 逆行生长 → 成为星空 |
| 「时间停住了」 | 停滞 | 悬在半空的一滴水 | 下落 → 静止 → 爆开成钟面 |

母题检验（三条全过才继续）：

1. **名词可拍**：能建模/做材质/打光，不是抽象词。
2. **可重复**：至少能在 5 个镜头里以不同尺度出现。
3. **可变形**：有明确的开始状态与结束状态，中间至少两种中间态。

## 1.4 treatment 模板（≤400 字）

```
片名：<中文> / <英文>
母题：<一个可拍的东西>，从 <状态 A> 到 <状态 B>。
一句话：<谁/什么> 为了 <欲望>，穿过 <障碍>，最后 <落点>。

弧线：
- 建立（0:00–0:xx）：<世界与规则>，母题第一次出现，尺度 <微距/中景/广角>。
- 变形（0:xx–0:xx）：<规则被打破>，母题变成 <形态 2>，能量第一次上升。
- 峰值（0:xx–0:xx）：<最强烈的视觉事件>，全片最亮/最快/最密。
- 回落（0:xx–0:xx）：<尺度变大或变小>，母题回到 <形态 0 但意义不同>。
- 落点（0:xx–0:xx）：<最后一个画面>，字幕/片名。

视觉规则（写死，后面不许违反）：
- 只允许 <色 1><色 2><色 3> + 一个强调色 <色 4>。
- 光只从 <方向> 来，色温 <K>。
- 镜头：<焦段范围>，运动 <缓慢/手持/机械>。
- 禁止：<塑料高光/饱和霓虹/快速变焦/…>。
```

示例（《我爱你》）：

> 母题是一封没有寄出的信。它从墨滴中诞生，穿过海面、鱼群、纸阶、红线与镜面，
> 最后成为月光下的一层光。全片只用墨黑、银白、宣纸米色与火漆红；光只从上方来。
> 镜头 35–85mm，运动缓慢，禁止快速变焦与饱和色。文字是原创诗行，不引歌词。

## 1.5 三张风格帧怎么出

不要「生成三张漂亮图」。三张帧必须**回答三个不同问题**：

1. **材质帧**：母题的最大特写。回答「这东西摸起来是什么」。
2. **空间帧**：母题所在环境的广角。回答「世界有多大、光从哪来」。
3. **文字帧**：片名或一句字幕压在画面上的样子。回答「文字如何存在」。

三张帧必须来自同一套色板与光位。用户的选择不是「哪张好看」，而是
「哪张代表了你要的质感」——选定后，把它的颜色、对比、颗粒、字体写进
`art-direction.json`，作为全片基准。

**风格帧的常见错误**：

- 三张帧像三部不同的片子（无法锁定）
- 只有氛围，没有主体（搭场景时无法对齐）
- 文字帧字号过大/过小（字幕系统会重做）
- 用了最终不会出现的元素（用户会期待它出现在片子里）

## 1.6 锁定美术方向

`art-direction.json` 是全片的「宪法」。字段与含义见 `schemas/art-direction.schema.json`。
必须写死的：

| 字段 | 为什么必须写死 | 例子 |
|---|---|---|
| `palette` | 防止每个场景各调各的 | `#06080d, #1b2433, #c9d3e0, #e8e2d4, #b3342c` |
| `materials` | 决定所有着色器 | `paper, ink, silver, wax` |
| `forbidden` | 比「要什么」更能防漂移 | `plastic specular, saturated neon, lens flare` |
| `light` | 统一所有场景的立体感 | `top, 5600K, contrast 0.75, volumetric false` |
| `lens` | 统一空间感 | `35/50/85mm, shake 0.035, no zoom` |
| `type` | 统一文字气质 | `Noto Serif SC 300 / Cormorant Garamond italic` |
| `post` | 统一「胶片感」 | `bloom .28 @ .82, grain .035, vignette .35, CA .0008` |
| `transitions` | 统一语法 | `ink, dip, fade` only |

批准后，任何改动都要在文件里留一条 `changelog`，并说明原因。**没有 changelog 的改动视为漂移。**

## 1.7 用户改主意怎么办

- 改动在 Gate A 之前：免费。
- 改动在 Gate A 之后、Gate C 之前：重开 Gate A，重出 3 张风格帧，**只重做受影响的场景**。
- 改动在 Gate C 之后：评估「换风格」vs「换一部片」。通常换一部 30 秒版更便宜。
- 用户说「再高级一点」：这不是有效指令。追问「是更暗、更慢、更空、还是更精细？」
  把它转成 art-direction 里的一个具体字段。

## 1.8 一句话交付检查

treatment 写完后，用一句话复述给用户：

> 「这是一部关于 <母题> 的片子：它从 <A> 变成 <B>，最强烈的一刻在 <时间>，
> 最后停在 <落点>。全片只有 <颜色>，<禁止项> 不会出现。」

用户点头，才进入音乐地图与分镜。
